# 老必灯 · 键盘灯效工作室

老必灯是 Windows 键盘灯效程序，提供 66 种灯效、RGB 色盘、本地照片键位编辑器和系统托盘控制。目前实物逐键灯光已适配 VGN V98 Pro 的 USB 有线与 2.4G 接收器。

## 启动和退出

普通用户下载 Releases 中的 `LaoBiDeng-Setup-1.3.5.exe`，双击安装后从桌面或开始菜单启动，无需单独安装 Python。首次启动会扫描已连接的 HID 键盘，自动读取 VID/PID 和设备报告的型号；识别到已适配的 V98 Pro 可直接使用。系统只报告通用名称或连接了多把键盘时，可在设备设置里选择和修正。

目前安装包尚未签名，开启 Windows Smart App Control 的电脑可能阻止安装或启动。正式解决需要可信的代码签名证书；请不要为此关闭系统防护。源码和安装包均在本项目的 GitHub Releases 发布。

从源码运行时可双击 `启动老必灯.bat`。它会在本地创建 Python 环境并安装依赖；旧的 `启动涟漪灯效.bat` 仍可使用。

窗口右上角关闭按钮会将程序收进系统托盘，灯效继续运行。托盘图标右键菜单有“显示窗口”“暂停灯效”和“退出程序”。窗口底部也有“退出程序”。暂停时保持底色常亮。

请勿让其他灯控软件同时控制同一键盘；多个程序同时发送灯光帧可能造成闪烁。

## 灯效与颜色

灯效画廊分为常规 21 种、按键互动 21 种、音乐交互 21 种和自定义灯效 3 种。四个分类按钮可分别展开或收起，同一时间最多展开一个分类。自定义灯效包括“自绘心跳”“逐键画布”和“自绘星图”。暗色涟漪默认以黑色波纹色在常亮底色上扩散；连续按键产生的涟漪可以同时走完。新增的数字雨、按键回声、扫描光束和音乐可视化玩法参考了 [QMK RGB Matrix](https://github.com/qmk/qmk_firmware/blob/master/docs/features/rgb_matrix.md) 与 [OpenRGB Effects Plugin](https://openrgb.org/plugin_effects.html) 的效果类别，动画计算由本项目按键位坐标独立实现。

音乐灯效在后台读取 Windows 默认播放设备的回环声音，只在内存中分析低频、中频、高频和节拍，不保存声音。鼓点由短音频块优先触发；所有音乐灯效共用较弱的持续中低频、较醒目的强拍响应和快速起音。新增音乐灯效只要加入 `MUSIC` 分类，就会继承这套响应。节拍光环持续轻微流动，重拍叠加扩散光环；“三频跃动”分区显示三个频段；“心电波”在白色常亮键盘上绘制跟随音乐滚动的心电线，不带固定爱心图案。无法打开回环分析时，自动回退到音量检测。切换默认播放设备后，点击“刷新音频设备”重新连接。

只有“自定义灯效”支持直接在键位预览中绘制：左键点一次选中，再点一次取消；拖动沿用起点的绘制或擦除状态，右键始终擦除。也可清空、全部点亮和保存。“自绘心跳”让所选键组成自绘图案，鼓点使图案跳动；音乐心电线从图案后方经过，未选中的键保持白色。“逐键画布”将所选键固定为点缀色，其余键保持底色；“自绘星图”让所选键依次闪亮。常规、按键互动及音乐交互的键位预览只显示灯效，不能在预览中编辑。

Fn 可作为独立灯位在自定义画布中点亮。Fn 是键盘固件功能键，按下时是否触发互动灯效取决于键盘是否向 Windows 上报按键事件。

画廊下方的配色区对应当前选中的灯效。暗色涟漪可以分别调整“底色”和“波纹色”；其余效果分别使用“底色”和“点缀色”。点击色块打开自绘 RGB 色盘，可拖动选择色相、鲜艳度和明暗，也可输入 RGB 数值或十六进制颜色。选色时即时预览，点击“应用颜色”保存；切换到其他窗口或收起程序时也会保存当前颜色。点击“取消”或按 Esc 会恢复原色。配色区另有清新、暖调、霓虹、柔和共 24 组可一键套用的双色方案；所选两色均为可发光颜色，避免暗色点缀在实体键盘上几乎不可见。在“心电波”中，第二色用作背景。“心电波”可调整心电线颜色；“自绘心跳”可分别调整心电线和自绘图案的颜色。每种灯效分别记住自己的配色；全键常亮只使用底色。“整体亮度”可在 0%–100% 间调整，“动画速度”可在 0.2×–3.0× 间调整。选中有宽度的灯效时还可调整 50%–200% 的“光带宽度”；其他灯效不显示这项设置。数值都能拖动滑块或直接点击输入。个人设置保存在 `%LOCALAPPDATA%\老必灯\settings.json`。

底色和点缀色的亮度可分别调整；全局亮度继续控制整把键盘。“全局颜色”是一颗共用色块，选好后点击应用即可同步为所有灯效的底色。固定“心电波”和“自绘心跳”另有独立的背景色入口，默认白色，可用 RGB 色盘改变。可把当前颜色、各项亮度、动画速度和光带宽度保存成命名预设；应用预设后切换灯效仍沿用这套设置，手动调整不会覆盖已保存的预设。

## 连接方式

| 模式 | 状态 | 接口 |
| --- | --- | --- |
| USB 有线 | 已接入并在本机运行 | `320F:5055` HID 灯控接口 |
| 2.4G 接收器 | 本机实测可稳定逐键控制；动态画面约 5 帧/秒，涟漪有明显顿帧 | `320F:5088` HID 灯控接口 |
| 蓝牙 | 本机识别到连接；自定义逐键灯控不可用 | HID 无 RGB 输出报告；发现的可写 GATT 特征属于固件升级通道 |

点击主窗口的“设置”，可修改键盘型号、照片键位和连接方式。自动模式优先选择在线的 2.4G 接收器，否则选择 USB 有线。键盘切到蓝牙时，即使 2.4G 接收器还插在电脑上，程序也会停止向接收器发送灯光帧并显示蓝牙状态。拔插设备或切换模式后，程序会持续尝试重新连接。2.4G 帧在后台线程完整发送，以保持底色稳定；屏幕预览显示最近一次发送完成的画面。

程序在电脑睡眠后恢复运行时会重新打开灯控接口；发生短暂 HID 写入中断时立即尝试恢复，并继续定时重试。2.4G 旧发送线程不会在重连后继续向新连接写入数据。运行状态和连接异常记录在 `%LOCALAPPDATA%\老必灯\runtime.log`，方便排查偶发闪断。

这台接收器实测每帧需发送 16 个报告，每包间隔 12 毫秒才能避免局部闪烁与漏灯，因此完整画面约每秒更新 5 次。4、6、8 毫秒间隔都出现漏灯。软件无法在保持完整画面的同时达到键盘固件原生涟漪的流畅度；USB 有线模式的逐键发送更快，适合使用自定义暗色涟漪。

蓝牙模式下仍可用键盘固件自带的灯效；使用 `Fn+PgUp` / `Fn+PgDn` 切换。本机的蓝牙 HID 集合没有 RGB 输出报告，唯一发现的可写自定义 GATT 特征与[厂商提交的固件升级通道说明](https://fccid.io/m/915ea8f323a92fbbdee19ce3ec8b090883a842b85ed379eab2aaebed9d185d6b.pdf)相符，因此程序不会向它发送灯光数据。根据 VGN 官方说明书，蓝牙和 2.4G 模式下键盘闲置 3 分钟会自动关闭灯光，这是键盘固件的省电行为。

## 其他键盘

首次配置其他型号时，先从自动扫描结果中选择键盘；若型号未上报或设备未出现，可以手动修正型号与 VID/PID。仍须提供照片以校准键位。内置的本地编辑器可套用 61、87、104 键或 V98 Pro 初始布局，用户可在照片上拖动、缩放、增删键帽并修改键名。保存后，程序使用这份布局绘制屏幕灯效，按键响应也从对应键位开始。新型号的实物灯光仍需其灯控协议；尚未适配时会明确显示“仅屏幕预览”。设置页还能导出适配资料 ZIP，具体要求见 [COMPATIBILITY.md](COMPATIBILITY.md)。

## 开发与打包

安装 `requirements-build.txt` 后，运行 `build_release.ps1`。脚本使用 PyInstaller 打包独立程序，再用 Inno Setup 6.7 编译深灰和青柠主题的 Windows 安装包，输出位于 `release/`。构建机器需安装 Inno Setup 6；最终用户无需这些工具。

## 项目文件

- `main.py`：入口与日志。
- `ui_app.py`、`ui.qss`：窗口、托盘、色盘与界面布局。
- `device_detection.py`、`device_setup.py`：设备自动识别、型号确认与本地照片键位编辑器。
- `layout.py`：按用户提供的键盘照片绘制的 97 键键帽位置。
- `effects.py`、`audio_spectrum.py`、`audio_meter.py`：66 种逐键灯效与系统播放声音分析。
- `backend.py`、`keyboard_map.json`：按键监听、有线与 2.4G HID 数据发送。
- `assets/ripple.svg`：图标矢量源文件。
- `installer.iss`、`build_release.ps1`：一键安装包的编译配置。
- `inspect_video.py`：独立的视频分析工具；需要时运行 `pip install -r requirements-video-tools.txt` 安装可选媒体组件。键盘灯效程序不依赖这组组件。

灯控数据格式参考 [SignalRgb_CN_Key 的有线驱动](https://github.com/NollieL/SignalRgb_CN_Key/blob/main/VGN%20Series.js)和[无线驱动](https://github.com/NollieL/SignalRgb_CN_Key/blob/main/VGN98Pro_Wireless.js)。灯效设计参考 [OpenRGB Effects Plugin](https://openrgb.org/plugin_effects.html)、[KeyboardVisualizer](https://github.com/CalcProgrammer1/KeyboardVisualizer)、[fizz-rgb](https://github.com/MrSchrodingers/fizz-rgb) 与 [keyRGB](https://github.com/Rainexn0b/keyRGB)；逐键动画计算由本项目独立实现。键盘模式和休眠行为见 [VGN V98pro 官方说明书](https://cdn.vgn.cn/download/v98pro%E8%AF%B4%E6%98%8E%E4%B9%A6.pdf)。

安装器使用 [Inno Setup 简体中文翻译](https://github.com/jrsoftware/issrc/blob/main/Files/Languages/ChineseSimplified.isl)，原维护者为 Zhenghan Yang (Kira)。

音乐分析使用 [SoundCard](https://github.com/bastibe/SoundCard) 和 [NumPy](https://numpy.org/)；相关许可文件随安装包提供在 `third_party/` 与 NumPy 的包信息目录中。
