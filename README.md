# 老必灯 · 键盘灯效工作室

老必灯是 Windows 键盘灯效程序，提供 18 种动画、RGB 色盘、本地照片键位编辑器和系统托盘控制。目前实物逐键灯光已适配 VGN V98 Pro 的 USB 有线与 2.4G 接收器。

## 启动和退出

普通用户下载 Releases 中的 `老必灯-Setup-1.0.0.exe`，双击安装后从桌面或开始菜单启动，无需单独安装 Python。首次使用须确认键盘型号和 4 位十六进制的 USB VID/PID；不清楚可咨询外设客服或 AI 工具，并以电脑实际识别的信息为准。

从源码运行时可双击 `启动老必灯.bat`。它会在本地创建 Python 环境并安装依赖；旧的 `启动涟漪灯效.bat` 仍可使用。

窗口右上角关闭按钮会将程序收进系统托盘，灯效继续运行。托盘图标右键菜单有“显示窗口”“暂停灯效”和“退出程序”。窗口底部也有“退出程序”。暂停时保持底色常亮。

请不要同时让 VHUB 控制键盘，否则两套软件向键盘发送不同灯光帧可能造成闪烁。

## 灯效与颜色

灯效画廊提供 18 种效果，包括暗色涟漪、全键常亮、柔和呼吸、双色波浪、极光渐变、流星追逐、星光闪烁、像素雨、旋转光环、柔焰、按键回响，以及双色流转、渐变潮汐、往返扫描、浮游光点、流动拼色、晨光漫染和呼吸光圈。默认只显示前 6 种，点击“查看全部 18 种”可浏览其余灯效。暗色涟漪默认以黑色波纹色在常亮底色上扩散；连续按键产生的涟漪可以同时走完。

画廊下方的配色区对应当前选中的灯效。暗色涟漪可以分别调整“底色”和“波纹色”；其余效果分别使用“底色”和“点缀色”。点击色块打开完整 RGB 色盘，可调整色相、饱和度、明度、RGB 数值及十六进制颜色。选色时即时预览，点击“应用颜色”保存；切换到其他窗口或收起程序时也会保存当前颜色。点击“取消”或按 Esc 会恢复原色。每种灯效分别记住自己的配色；全键常亮只使用底色。“常亮亮度”可在 0%–100% 间调整，“动画速度”可在 0.2×–3.0× 间调整，“波纹宽度”可在 50%–200% 间调整。三个数值都能拖动滑块或直接点击输入。个人设置保存在 `%LOCALAPPDATA%\老必灯\settings.json`。

## 连接方式

| 模式 | 状态 | 接口 |
| --- | --- | --- |
| USB 有线 | 已接入并在本机运行 | `320F:5055` HID 灯控接口 |
| 2.4G 接收器 | 本机实测可稳定逐键控制；动态画面约 5 帧/秒，涟漪有明显顿帧 | `320F:5088` HID 灯控接口 |
| 蓝牙 | 本机识别到连接；自定义逐键灯控不可用 | HID 无 RGB 输出报告；发现的可写 GATT 特征属于固件升级通道 |

点击主窗口的“设置”，可修改键盘型号、照片键位和连接方式。自动模式优先选择在线的 2.4G 接收器，否则选择 USB 有线。键盘切到蓝牙时，即使 2.4G 接收器还插在电脑上，程序也会停止向接收器发送灯光帧并显示蓝牙状态。拔插设备或切换模式后，程序会持续尝试重新连接。2.4G 帧在后台线程完整发送，以保持底色稳定；屏幕预览显示最近一次发送完成的画面。

这台接收器实测每帧需发送 16 个报告，每包间隔 12 毫秒才能避免局部闪烁与漏灯，因此完整画面约每秒更新 5 次。4、6、8 毫秒间隔都出现漏灯。软件无法在保持完整画面的同时达到键盘固件原生涟漪的流畅度；USB 有线模式的逐键发送更快，适合使用自定义暗色涟漪。

蓝牙模式下仍可用键盘固件自带的灯效；使用 `Fn+PgUp` / `Fn+PgDn` 切换。本机的蓝牙 HID 集合没有 RGB 输出报告，唯一发现的可写自定义 GATT 特征与[厂商提交的固件升级通道说明](https://fccid.io/m/915ea8f323a92fbbdee19ce3ec8b090883a842b85ed379eab2aaebed9d185d6b.pdf)相符，因此程序不会向它发送灯光数据。根据 VGN 官方说明书，蓝牙和 2.4G 模式下键盘闲置 3 分钟会自动关闭灯光，这是键盘固件的省电行为。

## 其他键盘

首次配置其他型号时，须输入型号、VID/PID 并提供照片。内置的本地编辑器可套用 61、87、104 键或 V98 Pro 初始布局，用户可在照片上拖动、缩放、增删键帽并修改键名。保存后，程序使用这份布局绘制屏幕灯效，按键响应也从对应键位开始。新型号的实物灯光仍需其灯控协议；尚未适配时会明确显示“仅屏幕预览”。设置页还能导出适配资料 ZIP，具体要求见 [COMPATIBILITY.md](COMPATIBILITY.md)。

## 开发与打包

安装 `requirements-build.txt` 后，运行 `build_release.ps1`。脚本使用 PyInstaller 打包独立程序，再用 Inno Setup 6.7 编译深灰和青柠主题的 Windows 安装包，输出位于 `release/`。构建机器需安装 Inno Setup 6；最终用户无需这些工具。

## 项目文件

- `main.py`：入口与日志。
- `ui_app.py`、`ui.qss`：窗口、托盘、色盘与界面布局。
- `device_setup.py`：型号确认与本地照片键位编辑器。
- `layout.py`：按用户提供的键盘照片绘制的 97 键键帽位置。
- `effects.py`：18 种逐键动画。
- `backend.py`、`keyboard_map.json`：按键监听、有线与 2.4G HID 数据发送。
- `assets/ripple.svg`：图标矢量源文件。
- `installer.iss`、`build_release.ps1`：一键安装包的编译配置。
- `inspect_video.py`：独立的视频分析工具；需要时运行 `pip install -r requirements-video-tools.txt` 安装可选媒体组件。键盘灯效程序不依赖这组组件。

灯控数据格式参考 [SignalRgb_CN_Key 的有线驱动](https://github.com/NollieL/SignalRgb_CN_Key/blob/main/VGN%20Series.js)和[无线驱动](https://github.com/NollieL/SignalRgb_CN_Key/blob/main/VGN98Pro_Wireless.js)。新增灯效的类型参考了 [OpenRGB Effects Plugin](https://github.com/DLdota/OpenRGBEffectsPlugin/blob/master/README.md) 与 [keyRGB](https://github.com/Rainexn0b/keyRGB) 的效果列表，逐键动画计算由本项目独立实现。键盘模式和休眠行为见 [VGN V98pro 官方说明书](https://cdn.vgn.cn/download/v98pro%E8%AF%B4%E6%98%8E%E4%B9%A6.pdf)。

安装器使用 [Inno Setup 简体中文翻译](https://github.com/jrsoftware/issrc/blob/main/Files/Languages/ChineseSimplified.isl)，原维护者为 Zhenghan Yang (Kira)。
